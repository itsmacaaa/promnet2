📌 Deskripsi

Personal Website merupakan website pribadi sederhana yang dibuat sebagai bagian dari tugas Pemrograman Internet. Website ini berfungsi sebagai media untuk memperkenalkan profil diri, menampilkan beberapa project yang pernah dikerjakan, serta menyediakan halaman kontak yang dapat digunakan untuk mengirim pesan.

Website ini dibuat menggunakan HTML dasar tanpa CSS, sehingga project berfokus pada penerapan struktur dan elemen-elemen dasar HTML seperti heading, paragraph, hyperlink, image, list, table, dan form.

🎯 Tujuan Project

Project ini bertujuan untuk:

Mempelajari dasar-dasar HTML.
Memahami struktur halaman dalam sebuah website.
Menerapkan penggunaan hyperlink untuk menghubungkan beberapa halaman.
Menampilkan informasi pribadi menggunakan elemen HTML.
Membuat tabel untuk menyajikan data dan ringkasan project.
Membuat form kontak sederhana.
Mengenal proses pembuatan website menggunakan Visual Studio Code.
📄 Halaman Website

Website terdiri dari empat halaman utama:

🏠 Home

Halaman utama yang berisi perkenalan singkat, foto profil, serta beberapa teknologi dan materi yang sedang dipelajari.

👤 About

Berisi informasi mengenai profil, data diri, hobi, dan riwayat pendidikan.

💻 Project

Menampilkan beberapa project yang pernah atau sedang dikerjakan, yaitu:

Website WESTRA — website dengan tema makanan Jawa Barat.
Game Kreswara Studio — game yang dibuat menggunakan Ren'Py.
Dataset Hotel Reservations — pengolahan dataset hotel menggunakan Python.
Sistem Informasi Peminjaman di Perpustakaan — project sistem informasi menggunakan XAMPP, VS Code, dan MySQL.
📩 Contact

Menyediakan informasi kontak serta form yang dapat digunakan untuk memasukkan nama, email, nomor telepon, jenis kelamin, tanggal lahir, topik pesan, dan pesan.

Catatan: Form kontak pada project ini masih berupa form HTML dan belum terhubung dengan database atau server.

Download atau clone repository.

Buka file Home.html.
Jalankan menggunakan browser atau extension Live Server.
Gunakan navigation menu untuk berpindah ke halaman Home, About, Project, dan Contact.
